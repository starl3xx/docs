## What HP is

Every token on the leaderboard is scored 0–100 every five minutes. The
score is called **HP**. At the hard cut (hour 96), the bottom six HP
ranks are filtered. The same ranking determines the finalist field
heading into settlement at hour 168.

HP is a weighted composite of six on-chain signals computed at t+96h
post-launch. Each signal targets a different failure mode the protocol
needs to detect:

| Component | What it measures | Why it matters |
|---|---|---|
| velocity | Decayed net buy inflow with sybil dampening | Tokens with no buyers can't survive |
| effectiveBuyers | sqrt-dampened headcount of meaningful buyers | One whale ≠ a real cohort |
| stickyLiquidity | Time-weighted LP depth penalised by recent withdrawals | LP that comes and goes is not LP |
| retention | Two-anchor (long + short) holder retention fraction | Are early buyers still holding? |
| momentum | Recent base-composite delta | (Currently zeroed — see methodology) |
| holderConcentration | HHI-mapped holder distribution | Concentrated bags ≠ a healthy market |

The current weight set is `2026-05-03-v4-locked`:

| Component | Coefficient |
|---|---:|
| velocity | 0.30 |
| effectiveBuyers | 0.15 |
| stickyLiquidity | 0.30 |
| retention | 0.15 |
| momentum | 0.00 |
| holderConcentration | 0.10 |

For the empirical derivation of these coefficients — what was tried,
what was rejected, and how the values cross-validate against published
research on adjacent launchpads — see
[**HP methodology**](/protocol/hp-methodology).

For the technical formulas + per-component spec references, see
[filter.fun spec §6.4](https://github.com/starl3xx/filter-fun/blob/main/filter_fun_comprehensive_spec.md#64-component-definitions).

## How weight changes work

Weights are off-chain config. Contracts read an oracle-signed Merkle
root of rankings, not the per-component coefficients — so a weight
change is enforceable only when the oracle reposts a new root under
the new set.

A weight change requires:

1. Empirical justification on a corpus of ≥200 tokens (Track E or
   successor), reported as Spearman ρ + AUC vs the locked outcome
   label.
2. Spec §6.5 amendment + external operator review.
3. ≥7-day public notice of the proposed activation date.
4. Indexer redeploy with the new `LOCKED_WEIGHTS` and a bumped
   `HP_WEIGHTS_VERSION` string.
5. The next oracle Merkle root posts under the new ranking.

Anyone can verify what's running at any time via the live
`/scoring/weights` endpoint.
