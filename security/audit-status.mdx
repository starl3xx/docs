## Voluntary disclosure window

A 14-day window during which the contracts are open for community review
before formal audit begins. This is **voluntary** — there is no paid
bounty in this window. See the [settlement security page](/security/settlement#voluntary-disclosure-window)
for scope, contact, and disclosure terms.

After the window closes, all findings (with reporter consent) are
documented on this page along with the response. Findings that surface
during the audit itself are documented separately as part of the audit
report.

## Mainnet activation gate

filter.fun does **not** activate Base mainnet on a calendar date.
It activates when this checklist completes:

- [x] Foundry invariant test suite shipped and passing
- [x] Public sankey diagram + invariant explainer
- [ ] 2-week public review window completed
- [ ] All public-review findings addressed or explicitly accepted-as-design
- [ ] Formal audit complete with public report
- [ ] All critical / high audit findings resolved
- [ ] Bag-lock contract covered in same audit
- [ ] Multi-sig on TreasuryTimelock + POLVault confirmed
- [ ] Sepolia smoke runbook executed cleanly at least once

Until every box is checked, mainnet contract activity is not authorized.
This is a published commitment, not an internal preference.
